Member constant which evaluates to {\ttfamily true} if all fields describe trivially copyable types. 

That is, for each field {\ttfamily F}, if {\ttfamily T} is {\ttfamily F\+::stored\+\_\+type}, then {\ttfamily std\+::is\+\_\+trivially\+\_\+copyable$<$\+T$>$\+::value} evaluates to {\ttfamily true}.

Otherwise, it evaluates to {\ttfamily false}.

If {\ttfamily true}\+:


\begin{DoxyItemize}
\item The record is effectively trivially copyable, meaning instances can be safely copied using {\ttfamily memcpy}/{\ttfamily memmove}, {\bfseries{and}}
\item The copy and move constructors and assignment operators are trivial, {\bfseries{and}}
\item The exception specifications of the copy and move constructors and assignment operators are {\ttfamily noexcept}. 
\end{DoxyItemize}
