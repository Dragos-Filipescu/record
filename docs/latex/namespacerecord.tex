A heterogeneous record container with compile-\/time layout optimization. 

Fields are reordered by alignment (descending) to minimize internal padding. The class maintains a distinction between Declaration Order (logical) and Storage Order (physical).

Initialization is performed via order-\/agnostic type-\/safe bindings.

Multiple Fields may share the same {\ttfamily storage\+\_\+type} but the field types themselves must be unique to avoid ambiguity.
