Models a field descriptor with semantic operations. 

In order for a type {\ttfamily T} to satisfy the concept {\ttfamily Field}, it {\bfseries{must}} provide\+:


\begin{DoxyItemize}
\item {\ttfamily T\+::stored\+\_\+type}\+: A typedef of the underlying data type. It must be a non-\/abstract object type, with a non-\/throwing destructor.
\end{DoxyItemize}

The type {\ttfamily T} {\bfseries{may}} additionally provide\+:


\begin{DoxyItemize}
\item {\ttfamily T\+::alignment}\+: A static member of type {\ttfamily std\+::size\+\_\+t}. This enforces memory alignment for the field.
\item {\ttfamily T\+::equals}\+: A functor for equality comparison, {\bfseries{and}}
\item {\ttfamily T\+::compare\+\_\+three\+\_\+way}\+: A functor for three-\/way comparison.
\end{DoxyItemize}

It is intended for users to inherit {\ttfamily \mbox{\hyperlink{structrecord_1_1field_1_1RecordField}{Record\+Field}}}, which already provides defaults for all 4, and which may be overridden as desired.
