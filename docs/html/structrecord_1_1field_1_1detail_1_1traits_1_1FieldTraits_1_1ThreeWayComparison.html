Member constant which evaluates to true if all fields describe three way comparable types.

That is, for each field F, if T is F::stored_type, then std::three_way_comparable<T> evaluates to true.

Otherwise it evaluates to false.

If true:

  • An ADL helper friend for three way comparison (compare), participates in overload resolution.

Member constant which evaluates to true if all fields describe nothrow three way comparable types.

That is, for each field F, if T is F::stored_type, then noexcept(std::declval<const T&>() <=> std::declval<const T&>()) evaluates to true.

Otherwise it evaluates to false.

If true:

  • The exception specifications of the three way comparison helper (compare) is noexcept.
