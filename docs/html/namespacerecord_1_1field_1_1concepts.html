template<typename T >
concept record::field::concepts::Field = detail::Storable<T>

Models a field descriptor with semantic operations.

In order for a type T to satisfy the concept Field, it must provide:

  • T::stored_type: A typedef of the underlying data type. It must be a non-abstract object type, with a non-throwing destructor.

The type T may additionally provide:

  • T::alignment: A static member of type std::size_t. This enforces memory alignment for the field.
  • T::equals: A functor for equality comparison, and
  • T::compare_three_way: A functor for three-way comparison.

It is intended for users to inherit RecordField, which already provides defaults for all 4, and which may be overridden as desired.
