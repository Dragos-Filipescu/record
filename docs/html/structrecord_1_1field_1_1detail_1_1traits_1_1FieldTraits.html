Detailed Description

template<concepts::Field... Fields>
struct record::field::detail::traits::FieldTraits< Fields >

Type traits for a collection of Fields.

Contains conjunctions over various STL type traits, such as:

  • std::is_trivially_copyable
  • Destruction traits
  • Default Construction traits
  • Move/Copy Semantics traits
  • Equality and Three Way Comparison traits
Template Parameters
FieldsA type pack, each satisfying the concept Field

The common comparison category of all fields.

That is, the weakest category that can represent the result of comparing any two fields of this type.

If the pack is empty, defaults to std::strong_ordering.

Member constant which evaluates to true if all fields describe trivially copyable types.

That is, for each field F, if T is F::stored_type, then std::is_trivially_copyable<T>::value evaluates to true.

Otherwise, it evaluates to false.

If true:

  • The record is effectively trivially copyable, meaning instances can be safely copied using memcpy/memmove, and
  • The copy and move constructors and assignment operators are trivial, and
  • The exception specifications of the copy and move constructors and assignment operators are noexcept.
