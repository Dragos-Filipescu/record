Performs lexicographic three-way comparison between two Records.Compares fields sequentially according to the specified order, returning the first non-equivalent result. If all fields compare equivalent, returns the weakest common comparison category among fields, as determined by `std::common_comparison_category_t< std::compare_three_way_result_t<typename Fields::stored_type>... >`.

Template Parameters
OrdComparison order:
  • ComparisonOrder::Declaration (default) – follows logical field order. Preserves the semantic precedence expected by users (e.g., surname before given name).
  • ComparisonOrder::Storage – follows physical layout. Cache-efficient, but may produce surprising ordering if fields are reordered for alignment.
Parameters
lhs,rhsRecords to compare.
Returns
A result of type std::common_comparison_category_t< std::compare_three_way_result_t<typename Fields::stored_type>...

Precondition
All field types must satisfy std::three_way_comparable. If a field type defines its own F::compare_three_way functor, it is used instead of std::compare_three_way.
Note
Defaults to Declaration order because comparison semantics often encode domain-specific precedence (e.g., sorting by last name, then first name). Storage order is provided for performance-sensitive contexts where any total order suffices.
