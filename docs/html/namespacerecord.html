template<template< typename... > typename Target>
using record::Rebind = typedef Target<Fields...>

A heterogeneous record container with compile-time layout optimization.

Fields are reordered by alignment (descending) to minimize internal padding. The class maintains a distinction between Declaration Order (logical) and Storage Order (physical).

Initialization is performed via order-agnostic type-safe bindings.

Multiple Fields may share the same storage_type but the field types themselves must be unique to avoid ambiguity.

Template Parameters
FieldsA pack of unique types.

Example:

struct Name {
using stored_type = std::string;
static constexpr size_t alignment = alignof(std::string);
};
struct Age {
using stored_type = int;
static constexpr size_t alignment = alignof(float);
};
// Fields are bound by type, making the constructor order-agnostic
Record<Name, Age> user{
Bind<Age>(25),
Bind<Name>("Alice")
};
auto& name = get<Name>(user);
auto&& [name, age] = user;

Constructs a record from a set of Field bindings.

Each Field in Fields... must be bound exactly once via Bind<F>(args...). Bindings may be supplied in any order. Each Field's stored value is constructed in-place from the arguments captured in its binding.

Template Parameters
BindsA pack of FieldBinding types, one per Field, in any order. Such types are a detail implementation and not to be instantiated directly, but rather via calling record::Bind and passing the respective arguments for the Field.
